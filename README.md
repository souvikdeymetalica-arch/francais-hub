# FrançaisHub v15

Professional bilingual French-learning build.

- Expanded online search fallback for English and French words.
- Dictionary definitions, parts of speech and examples when online data is available.
- English ↔ French translation workspace with online translation fallback.
- Curated CEFR B1–C1 vocabulary remains available offline.
- Live French news and crossword remain included.

## Oxford data
Oxford Languages provides an official Dictionaries API with French monolingual data, but its current supported bilingual translation datasets do not include English ↔ French. Oxford API requests require credentials. FrançaisHub therefore does not copy Oxford content or pretend that a free API is Oxford data. A licensed Oxford integration can be added through a secure server-side connection if you obtain the appropriate Oxford access.
